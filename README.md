# Caixa Eletrônico

Simulação de um caixa eletrônico em Java, executada pelo terminal.

## Funcionalidades
- Menu interativo com quatro opções
- Consulta de saldo (o saldo inicial é R$ 500,00)
- Depósito, aceitando apenas valores maiores que zero
- Saque, validando valor positivo e saldo suficiente
- Tratamento de entradas inválidas, como letras no lugar de números
- Encerramento pela opção 4

## Como executar
```bash
javac CaixaEletronico.java
java CaixaEletronico
```

## Tecnologias
Java
